# R-#18: Script `m` (wrapper) para @pasosdejesus/m (instalación local, rápido)

Crear un script `m` ligero que instale el CLI `@pasosdejesus/m` en un
directorio local y lo ejecute directo con `node`, evitando la sobrecarga de
`npx` en cada invocación. Se mantiene actualizado con un chequeo por TTL
cuando hay Internet y funciona sin red usando la copia instalada.

---

**Created:** 2026-08-05
**Status:** Pendiente

## Prioridad

Se prefiere un script ligero en lugar de un porte OpenBSD. La primera versión
usaba `npx @pasosdejesus/m@latest`, pero el arranque quedaba lento (~3.6 s)
porque `npx` resuelve `@latest` contra el registro en cada invocación (y el
wrapper lo hacía dos veces). Se cambió a:

- Instalar `@pasosdejesus/m` en `$M_DIR` (por defecto `~/.m-cli`) con `npm
  install --prefix`.
- Ejecutar `node $M_DIR/node_modules/@pasosdejesus/m/dist/m.js` directo
  (~0.7 s, el costo de arranque del propio CLI).
- Actualizar a `@latest` solo si pasaron `M_TTL` segundos (por defecto 86400
  = 1 día) desde la última actualización, y solo si hay conexión.

Así queda corto (`m`), rápido (~0.7 s), actualizado online y funcional
offline, sin el mantenimiento de un porte.

## Lógica del script

```sh
#!/bin/sh
M_DIR="${M_DIR:-$HOME/.m-cli}"
M_BIN="$M_DIR/node_modules/@pasosdejesus/m/dist/m.js"
M_STAMP="$M_DIR/.actualizado"
M_TTL="${M_TTL:-86400}"

# Detectar node/npm: el paquete node de OpenBSD incluye ambos
if ! command -v node >/dev/null 2>&1 || ! command -v npm >/dev/null 2>&1; then
  echo "m: se requiere el paquete node (incluye npm): doas pkg_add node" >&2
  exit 1
fi

instala() {
  npm install --prefix "$M_DIR" --no-fund --no-audit \
    @pasosdejesus/m@latest >/dev/null 2>&1
}

if [ ! -f "$M_BIN" ]; then
  if ! instala; then
    echo "m: no se pudo instalar @pasosdejesus/m (¿sin conexión?)" >&2
    exit 1
  fi
  date +%s > "$M_STAMP"
fi

ahora=$(date +%s)
ultimo=$(cat "$M_STAMP" 2>/dev/null || echo 0)
if [ "$M_TTL" = "0" ] || [ $((ahora - ultimo)) -ge "$M_TTL" ]; then
  if instala; then
    date +%s > "$M_STAMP"
  fi
fi

exec node "$M_BIN" "$@"
```

## Dependencia

Requiere `node` (que incluye `npm`). En adJ 7.9 ya está listado en
`Contenido.txt` y se instala desde el paquete estable de OpenBSD, así que no
requiere entrada en `distribucion.sh` (que solo se usa para paquetes que
necesitan recompilación). El wrapper detecta si falta `node`/`npm` al inicio
y sale con un mensaje claro (`doas pkg_add node`), en lugar de fallar con
`command not found`.
