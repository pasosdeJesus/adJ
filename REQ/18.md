# R-#18: Port of m

Create OpenBSD port for `@pasosdejesus/m` — the CLI tool that provides
`m ai:*`, `m req:*`, `m db:*`, `m wallet:*` and other project management
commands.

---

**Created:** 2026-08-05
**Status:** En progreso

## Summary

Package `m` v0.14.1 (single-package branch, not monorepo) as an OpenBSD
port under `devel/m` for inclusion in adJ 7.9. The tool is a Node.js CLI
that agents and developers use to interact with the project.

## Notes

- The distfile bundles node_modules to avoid network during port build.
  This is temporary — once upstream publishes to npm, `npm install --omit=dev`
  can be used in `do-build` with proper `FETCH_PACKAGES`.
- The `ia/` directory is included in the package so `m ai:framework` and
  `m ai:verify` find alignment files at
  `/usr/local/lib/node_modules/@pasosdejesus/m/ia/`.
- port must set `PKGNAME = m-0.14.1`; final package name will be `m`.
